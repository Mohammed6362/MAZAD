## المنجز

- واجهة React وTailwind عربية، وخلفية Express وPostgreSQL، مع حساب موحد للبيع والمزايدة وصلاحية إدارة مستقلة.
- إضافة السيارات والصور ومراجعتها، والبحث حسب 115 ماركة و1409 خيارات موديل مع إدخال يدوي.
- مظهر فاتح وداكن وحسب الجهاز، مع حفظ الاختيار في `mazad-theme` ومزامنته بين التبويبات.
- مزاد تصاعدي مباشر، حجز كامل العرض الأعلى، فك حجز العرض المتجاوز، وتمديد دقيقتين في نهاية المنافسة وإغلاق تلقائي.
- محفظة وهمية بالدينار الليبي؛ لا توجد أموال حقيقية أو سحب مصرفي.
- مهلة سداد افتراضية 48 ساعة وافق عليها المستخدم، قابلة للتغيير من الإدارة لكل مزاد بين 1 و168 ساعة. انتهاء المهلة يلغي الفوز ويفك الحجز دون غرامة ويعيد السيارة للمراجعة؛ لا ينتقل الفوز تلقائيًا للمزايد التالي.
- السداد التجريبي يحفظ الرصيد في ضمان المعاملة. يسجل البائع التسليم ثم يؤكد المشتري الاستلام، فتصرف الحصيلة للبائع مرة واحدة.
- اعتراض الطرفين قبل الإتمام يوقف الصرف، والإدارة تعالج الاعتراض أو تلغي المعاملة وتعيد الضمان. الإلغاء بعد إتمام البيع وصرف الحصيلة غير متاح آليًا. رد السداد اليدوي يتطلب تأكيد الإدارة لمعالجته خارج المنصة.
- صور الملكية إلزامية مع طلب السيارة (1–5 صور JPG/PNG/WebP، حتى 5MB للصورة)، محفوظة في مسار خاص ولا يفتحها إلا مدير نشط. اعتماد الطلب يتطلب إقرار المراجعة ورقم نسخته الحالي.
- تحديثات للحساب والمحفظة والفواتير ومزايداتي والإدارة، وسجل إجراءات ثابت وإشعارات مرتبطة بالمعاملات.
- منع تخزين ردود API في المتصفح عبر `Cache-Control: no-store`.

## حالة الحفظ والتحقق

- جميع تعديلات الكود محفوظة في ملفات المشروع. هذه نقطة توقف موثقة وليست Git commit؛ المجلد لم يكن مستودع Git عند الفحص السابق.
- طُبّقت تحديثات قاعدة البيانات حتى `012_sale_lifecycle.sql` على قاعدة التشغيل بعد أخذ نسخة احتياطية.
- النسخة السابقة للتحديث: `backups/mazad-2026-10-30T19-58-13-779Z-9Mh97f`؛ الاسم آلي كما هو على القرص.
- نجحت 9 اختبارات خلفية وتكامل و12 حالة متصفح على Chromium وFirefox وWebKit، إضافة إلى البناء والتنسيق.
- شملت الاختبارات 50 طلب مزايدة متزامنًا، وتكرار السداد والصرف والاسترداد، والمهلة بعد انتظار الأقفال، وخصوصية المستندات، وأحجام العرض وانقطاع الاتصال.
- استخدمت الاختبارات بيانات منفصلة؛ أكد آخر فحص عدم بقاء مخططات المعاينة والاختبار المؤقتة.
- كانت الخدمات المحلية تستجيب بنجاح عند آخر تحقق؛ تشغيلها لاحقًا يعتمد على بقاء عملية التشغيل.

تشغيل المشروع من المجلد الرئيسي: `npm.cmd run dev`، ثم فتح `http://localhost:5173`.
