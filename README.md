# مزاد ليبيا

لشرح وظائف الملفات والدوال ومسارات التسجيل والمزايدة والدفع، اقرأ [دليل قراءة الأكواد](docs/code-guide.md). تتضمن ملفات المشروع تعليقات عربية مرتبطة بهذا الدليل.

منصة سيارات بواجهة React وTailwind CSS، وخلفية Express وPostgreSQL. الواجهة عربية ومتوافقة مع اتجاه RTL.

## التشغيل اليومي

من مجلد المشروع الرئيسي، شغّل:

```powershell
npm.cmd run dev
```

يشغّل الأمر الواجهة على `http://localhost:5173` والخلفية على `http://localhost:3000` مع إعادة تحميل الكود عند التعديل. يتعرف على خدمات المشروع التي تعمل مسبقًا ويستخدمها دون تشغيل نسخ إضافية. إذا كان المنفذ محجوزًا لتطبيق آخر، يعرض رسالة قبل بدء أي خادم. اترك نافذة التشغيل الأصلية مفتوحة. لإيقاف الخدمات التي بدأتها هذه النافذة اضغط `Ctrl+C`. استخدام `npm.cmd` يتجنب مشكلة منع `npm.ps1` في PowerShell.

في Windows تقتصر مراقبة الخلفية على `src` و`server.js` و`.env`، لذلك تغييرات `node_modules` لا تعيد تشغيلها. عند الترقية من مشغّل قديم، أوقف نافذة التشغيل القديمة مرة واحدة ثم أعد الأمر.

لتشغيل الخلفية وحدها، نفّذ `npm.cmd run dev` من مجلد `backend`. يستخدم الأمر الخادم الموجود إذا كان يعمل مسبقًا، أو يبدأ خادمًا جديدًا عند توفر المنفذ. إذا ظهرت رسالة الخطأ من الأمر القديم `node --watch server.js`، أوقف تلك النافذة بـ `Ctrl+C` ثم أعد الأمر.

لتشغيل النسخة المبنية بخادم واحد:

```powershell
npm.cmd run build
npm.cmd start
```

افتح `http://localhost:3000` في هذا الوضع. الواجهة والخلفية والصور تستخدم العنوان نفسه، وتعمل روابط الصفحات عند تحديث المتصفح.

## الإعداد لأول مرة

1. ثبّت Node.js 22 أو أحدث وPostgreSQL.
2. شغّل `npm.cmd ci` ثم `npm.cmd run setup` من مجلد المشروع.
3. أنشئ قاعدة بيانات فارغة وطبّق عليها `backend/database/schema.sql` مرة واحدة. لا تُعِد تطبيق الملف على قاعدة موجودة.
4. أنشئ `backend/.env` اعتمادًا على `backend/.env.example` وحدّد اتصال قاعدة البيانات وسر جلسة عشوائيًا بطول 32 حرفًا على الأقل. احتفظ بملف إعداداتك الحالي إن كان موجودًا.
5. شغّل `npm.cmd run migrate` لتطبيق التحديثات، ثم `npm.cmd run dev`.

## الحسابات

كل مستخدم لديه حساب موحد لعرض سياراته والمزايدة على سيارات الآخرين، دون اختيار مشتري أو بائع أو تبديل الوضع. الحسابات السابقة دُمجت في الدور user مع الاحتفاظ بمعرفاتها وبياناتها. صلاحية الإدارة تُمنح لحساب نشط موجود فقط، ولا يمكن طلبها من صفحة التسجيل.

لتفعيل مدير بالبريد الإلكتروني، من مجلد `backend`:

```powershell
$env:ADMIN_EMAIL = 'your-existing-account@example.com'
npm.cmd run grant-admin
Remove-Item Env:ADMIN_EMAIL
```

يمكن استخدام `ADMIN_PHONE` بدلًا من `ADMIN_EMAIL`. لا تغيّر هذه العملية كلمة المرور.

## دورة العمل

يسجّل العارض حسابه مع صورة جواز خاصة بالإدارة، ويرفع السيارة وصورها وأوراق الملكية. يراجع المدير الطلب؛ عند أول اعتماد تُخصم رسوم عرض 10 د.ل من رصيد العارض المتاح. يستطيع العارض تعديل سيارته قبل وجود مزاد مفتوح، فتعود للمراجعة دون تكرار الرسوم. تحدد الإدارة صلاحيات العرض والمزايدة والإدارة من صفحة المستخدمين. بعد الاعتماد تُحدد الأسعار ومواعيد المزاد. التفاصيل في [سياسة الحساب والعرض](docs/account-policy.md).

يفتح المزاد للمزايدة في موعده. تمنع قاعدة البيانات مزايدة البائع على سيارته والعروض الأقل من الحد الأدنى، وتنسّق العروض المتزامنة بقفل سجل المزاد. يتوقف قبول العروض عند نهاية الوقت. يغلق الخادم المزاد المنتهي تلقائيًا كل خمس ثوانٍ، وتُنشأ فاتورة للفائز إذا تحقق حد البيع. تظهر الفاتورة لطرفي البيع؛ تسدد فواتير المحفظة برصيد وهمي، وتحتفظ الفواتير اليدوية السابقة بتأكيد الإدارة. لا توجد بوابة دفع حقيقية متصلة.

## التنظيم والفحص

راجع [تنظيم الملفات](docs/architecture.md) و[مسارات الخلفية](docs/api.md) و[دليل النشر والنسخ الاحتياطي](docs/deployment.md).
نتائج التحقق ونطاق الاختبارات موثقة في [اختبارات المشروع](docs/testing.md).

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run format:check
```

اختبار التكامل ينشئ مخططًا منفصلًا مؤقتًا داخل قاعدة البيانات، ويضع الصور في مجلد مؤقت، ثم ينظفهما. يحتاج مستخدم PostgreSQL إلى صلاحية إنشاء المخططات. لا يستخدم حسابات أو سيارات التشغيل، ولا يغيّر كلمات مرورها.

قبل النشر العام يلزم إعداد استضافة HTTPS، وضبط `NODE_ENV=production` خلف وكيل موثوق، والنسخ الاحتياطي لقاعدة البيانات والصور. تأكيد الهاتف واستعادة كلمة المرور عند نسيانها والإشعارات الخارجية والدفع الإلكتروني تحتاج خدمات خارجية ولم تُربط بخدمات حقيقية في هذه النسخة.

الإشعارات داخل الموقع تعمل دون مزود خارجي وتُحدّث كل 15 ثانية. تغييرات صور الطلبات تحفظ مع بيانات السيارة في معاملة واحدة، مع فك الصور والتحقق من محتواها وإزالة بياناتها الوصفية. يمكن إلغاء موعد مزاد قبل بدايته إذا لم تصله عروض.

النسخ الاحتياطي المحلي: `npm.cmd run backup`. تفاصيل الاستعادة وإعداد HTTPS وصلاحيات قاعدة بيانات الإنتاج في دليل النشر.

## الموديلات والمحفظة وآلية المزاد

الكتالوج يربط 1409 خيارات موديل بـ115 ماركة، مع إدخال يدوي للموديلات غير المدرجة، وفلتر موديل يتبع الماركة.

المحفظة: /account/wallet. شرح القواعد: /auction-rules. الرصيد والشحن والتحويل وهمي بالدينار الليبي. يحجز كامل العرض الأعلى ويفك عند تجاوزه، وتدفع فاتورة الفوز مرة واحدة من الحجز. توجد حماية من تكرار الشحن والدفع ومن تجاوز الرصيد في مزادات متزامنة.

السداد بمهلة افتراضية 48 ساعة؛ انتهاء المهلة يلغي الفوز ويفك الحجز. الدفع التجريبي يحفظ الرصيد في ضمان المعاملة حتى يسجل البائع التسليم ويؤكد المشتري الاستلام. يستطيع الطرفان الاعتراض قبل الإتمام، وتعالج الإدارة الاعتراض أو تلغي المعاملة وتعيد الضمان. أوراق الملكية ترفق مع السيارة وتفتح للإدارة فقط، ويلزم اعتمادها قبل جدولة مزاد جديد.

اختبارات المتصفحات على بيانات مستقلة (Chromium وFirefox وWebKit): ثبّت متصفحات Playwright مرة واحدة بـ `npx.cmd playwright install chromium firefox webkit` ثم شغّل `npm.cmd run test:e2e`. تشمل الرفع الخاص والمراجعة والسداد والتسليم والاسترداد وانتهاء المهلة، وأحجام 320/390/768/1366 والمظهر وانقطاع الاتصال. الصور والتقارير في `test-results` و`playwright-report` ولا تدخل في ملفات النشر. لا تستخدم هذه الاختبارات بيانات أو مستندات المستخدمين.

المزايدة في آخر دقيقتين تعيد العداد لدقيقتين، والإغلاق بعد النهاية تلقائي. اقرأ [القواعد والسياسة التجريبية](docs/auction-rules.md) للتفاصيل والفروق عن المنصات العالمية.
