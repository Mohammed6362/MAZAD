# منصة مزاد السيارات المحلي
Local Online Car Auction Platform

مشروع تخرج - قسم نظم المعلومات، كلية تقنية المعلومات، الجامعة الأسمرية الإسلامية
إشراف: د. فتحي ارحومة | العام الجامعي 2026

## الفكرة
منصة ويب لمزادات السيارات المستعملة محلياً، بمزايدة لحظية وشفافة،
مع مراجعة إدارية للإعلانات ونظام عربون لضمان الجدية.

## الفريق
- فرج مصطفى فرج العايب
- محمد جمعة سالم جابر
- هاشم علي محمد فريقيطة

## التقنيات
Node.js, Express, Socket.io, MySQL, JWT, HTML/CSS/JS, Bootstrap

## هيكل المشروع
- backend/ : الخادم والـ API
- frontend/ : واجهة المستخدم
- database/ : ملفات SQL
- docs/ : المتطلبات والمخططات

## التشغيل
1. cd backend
2. npm install
3. انسخ .env.example إلى .env وعدّل القيم
4. نفّذ database/schema.sql في MySQL
5. npm run dev
